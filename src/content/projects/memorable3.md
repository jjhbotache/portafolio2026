    Tercera iteración de **Memorable**, una plataforma para descubrir y guardar
    diseños con ayuda de IA.

    ## Funcionalidades de usuario

    - **Búsqueda**: filtro por etiquetas y buscador por palabras clave.
    - **Sugerencias con IA**: recomendaciones automáticas de diseños afines.
    - **Favoritos**: los usuarios registrados pueden guardar los diseños que les gusten.

    ## Administración

    - Gestión de diseños, etiquetas e información general de la página.

    ## Stack

    - **Frontend**: React + TypeScript, Redux Toolkit, Framer Motion.
    - **Backend**: Python + FastAPI sobre Postgres SQL.
    - **Infraestructura**: GCP, almacenamiento de imágenes en Cloudinary.
  en: |
    Third iteration of **Memorable**, a platform for discovering and saving designs
    with the help of AI.

    ## User features

    - **Search**: tag filters and keyword search.
    - **AI suggestions**: automatic recommendations of similar designs.
    - **Favorites**: registered users can save designs they like.

    ## Administration

    - Manage designs, tags and general page information.

    ## Stack

    - **Frontend**: React + TypeScript, Redux Toolkit, Framer Motion.
    - **Backend**: Python + FastAPI on Postgres SQL.
    - **Infrastructure**: GCP, images stored on Cloudinary.
