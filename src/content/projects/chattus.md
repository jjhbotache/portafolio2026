    Chattus es una plataforma de **chat temporal** sin registro: crea una sala y empieza
    a conversar al instante.

    ## Funcionalidades

    - **Mensajería rica**: mensajes, fotos, videos, audios y archivos.
    - **Salas configurables**: tiempo mínimo de actividad, requisito de mantener el foco
      en el chat, etc.
    - **Tiempo real**: comunicación con **WebSockets** entre frontend y backend.

    ## Stack

    - **Frontend**: React + TypeScript, Redux Toolkit, Styled Components, Vite.
    - **Backend**: Python + FastAPI.
  en: |
    Chattus is a **temporary chat** platform with no signup required: create a room and
    start talking right away.

    ## Features

    - **Rich messaging**: text messages, photos, videos, audio and files.
    - **Configurable rooms**: minimum uptime, focus-on-chat requirement, and more.
    - **Real-time**: **WebSockets** communication between frontend and backend.

    ## Stack

    - **Frontend**: React + TypeScript, Redux Toolkit, Styled Components, Vite.
    - **Backend**: Python + FastAPI.
