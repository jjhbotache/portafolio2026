content:
  es: |
    **DevKalk** es una PWA para que desarrolladores freelance armen presupuestos de
    proyecto combinando datos manuales con sugerencias de IA.

    ## Funcionalidades

    - **Gestión de funcionalidades y tareas**: alta, edición y borrado dinámico.
    - **Sugerencias de IA** para mejorar la precisión de la estimación.
    - **Exportación a PDF** del presupuesto final.
    - **Importación / exportación** de configuraciones del proyecto.
    - **PWA**: instalable y utilizable offline.

    ## Stack

    - **React + Vite** con **Redux Toolkit** para el estado.
    - **Tailwind CSS** para los estilos.
    - Iconografía con **Lucide React** y notificaciones con **React Toastify**.
  en: |
    **DevKalk** is a PWA that helps freelance developers build project quotations by
    combining manual inputs with AI-powered suggestions.

    ## Features

    - **Functionalities & tasks management**: dynamic create, edit and delete.
    - **AI suggestions** to improve estimation accuracy.
    - **PDF export** of the final quotation.
    - **Import / export** of project configurations.
    - **PWA**: installable and usable offline.

    ## Stack

    - **React + Vite** with **Redux Toolkit** for state management.
    - **Tailwind CSS** for styling.
    - Icons via **Lucide React** and notifications via **React Toastify**.
