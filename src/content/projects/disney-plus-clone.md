    Réplica pixel-perfect de la página de Disney+ usando únicamente **HTML** y **CSS**.

    ## Decisiones de diseño

    - **Sin librerías**: no se usó ninguna hoja de estilos existente ni framework de CSS.
    - **Metodología BEM**: aplicada para mantener un nombramiento de clases ordenado y
      escalable.
    - **Estrictamente pixel perfect**: la meta fue reproducir la apariencia original con la
      mayor fidelidad posible.
  en: |
    Pixel-perfect replica of the Disney+ page using only **HTML** and **CSS**.

    ## Design decisions

    - **No libraries**: no existing stylesheet or CSS framework was used.
    - **BEM methodology**: applied to keep class naming ordered and scalable.
    - **Strictly pixel perfect**: the goal was to reproduce the original look with the
      highest fidelity possible.
